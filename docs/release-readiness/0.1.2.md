## Implemented correctness work

- Worker results carry `AnalysisRunContext` with analysis kind, IDs, inputs, requested interval and catalog identity. Completed results retain original provenance across catalog refreshes.
- Selection/parameter edits invalidate output; delayed results are rejected; export names and Earth time handoff use the result identity.
- UTC normalization is applied before OMM conversion. Invalid elements are rejected rather than passed through as non-finite data.
- Phasing rejects a perigee at/below the WGS-72 surface, and Mission Design states the ideal circular two-body assumption. Derived heights are not labeled source data.
- Radial velocity/Doppler become null when supporting propagation fails. Charts retain gaps. AOS/LOS refinement requires a valid bracket; maximum elevation and minimum range are optimized independently.
- Proximity retains distinct encounters for the same secondary object, refines candidates and merges only duplicate local minima. It still provides screening, not covariance or collision probability.
- Coverage separates observation-window edge gaps from between-pass revisit gaps. Change Watch does not report normal conditions without enough snapshots.
- One request runs at a time; superseded requests are cancelled, long loops yield, stale responses are ignored, and the worker terminates on workspace exit/update handoff.
- CSV/JSON include provenance and units in field names. CSV has an `analysis-metadata` row followed by `measurement` rows: large catalog metadata is written once, not multiplied by every sample. Formula-leading strings are escaped. UI export failures are handled.
- Catalog warnings render a bounded set plus per-kind counts; full warnings remain in export.

## Data flow and update work

- Native scheduler owns recurring upstream refresh. The 3.5-minute frontend reconciliation reads native snapshots for CelesTrak/LL2/NASA/NOAA; a cold cache still uses the existing command to initialize data.
- Site weather records at most 16 recently used sites, reads cached snapshots in the UI, and refreshes active sites from the native scheduler while respecting the existing 15-minute weather TTL.
- Request mutexes, provider TTL/backoff and last-good disk caches remain. NOAA retries have a minimum five-minute scheduler delay. No generic freshness badges were reintroduced.
- Earth remains the existing warm instance/worker. Update handoff pauses it; SGP4, coordinates, LOD budgets and geometry were not changed to boost FPS.
- Public channel setting: `release/channel.json` → `IsrafilIsakhli/OrbitalVision-Releases`; versions align at 0.1.2 and the existing public key is preserved.
- Separate package builds carry a compiled package kind. Windows MSI/NSIS use distinct updater targets; Linux DEB/RPM are manual matching-package downloads; AppImage and macOS use native self-update.
- Optional updates stay opt-in. New checks continue while an older offer exists. Critical supported-package updates download first, drain writes/pause work, then install. Failure resumes application work; no unsafe install on a rejected download/signature.
- Native provider gates reject newly queued work during update handoff, after acquiring their request mutex. This closes the scheduler/check-to-lock race.
- The release workflow needs a token restricted to the binary repository, checks nine installer combinations plus updater sidecar signatures/checksums, rejects extra/source files and only creates a draft.
- Old clients with an inaccessible source-repository endpoint need one matching installer migration. Unknown Windows package types do not get a default EXE fallback.

## Open release gates — do not publish

1. **CSS budget:** initial roughly 239.6 kB was reduced to 194.9 kB using cascade deduplication, retired-style removal and the used CesiumWidget stylesheet. Another ~44.9 kB must be removed by reviewed component/style refactoring. A trial CSSO optimization saved only ~3.2 kB and was not added. `pnpm build` intentionally still fails the budget gate; increasing warning limits is not a solution. The generic Vite chunk warning now refers to the explicitly exempt Cesium engine only.
2. **Native dependency warnings:** review the GTK3/glib unsound/unmaintained chain and yanked chacha20 version. No unrelated major dependency rewrite was attempted.
3. **Real-provider native runtime:** cold start, populated Earth/Analysis, online→offline→reconnect, console/rejections, all six providers, real catalog counts and gateway recovery remain unverified in this run.
4. **Hardware performance:** no new FPS/P95, cancellation-time, pass/proximity timing, 50-switch primitive audit or 60-minute memory plateau measurement has been claimed. Browser UI/unit tests are not substitutes.
5. **Native installer/update matrix:** no new Windows installer release, macOS/Intel/Apple Silicon native session or Linux x64/ARM64 installation has been signed off. Test real interrupted/invalid-signature updates and actual package rollback on disposable installations.
6. **Public artifacts/token:** confirm the binary repository is public, supply `PUBLIC_RELEASES_TOKEN` restricted to that repository, run the draft build after local gates pass, then verify direct downloads and the website manifest. The 404 endpoint cannot currently prove direct installer downloads.
7. **Broader accessibility/visual coverage:** populated chart/table keyboard navigation, 320 px overflow inside panels, cross-workspace filter/scroll restoration and full five-language native visual QA need tester evidence. Page-level browser overflow checks alone are insufficient.
